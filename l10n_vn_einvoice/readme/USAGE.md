**Attaching an e-invoice.** Open a vendor bill, refund, customer invoice or credit note and click
*Attach E-Invoice*. Choose the invoice's XML file. The dialog shows what it read beside the
document and warns when the partner's tax code, the date or the total differs. *Attach* links the
e-invoice to the document without changing it; the file is kept on the e-invoice and a copy is
posted in the document's chatter.

**Lists.** *Vendors → E-Invoices* lists received e-invoices, *Customers → E-Invoices* issued ones,
each with its status: not booked, draft or booked.

**VAT codes.** *Configuration → Accounting → E-Invoice VAT Codes* maps each VAT code an e-invoice
writes (0%, 5%, 8%, 10%, KCT, KKKNT…) to a purchase tax. Creating bills from XML, which reads this
table, comes in a later version.
