1. Set the rate in *Manufacturing → Configuration → Settings → Costing → Conversion Cost per Minute*.
2. Enter *Conversion Minutes* on each normal bill of materials: the standard minutes per unit of the
   product.
3. A new manufacturing order shows the figure as *Extra Unit Cost* to Manufacturing administrators.
   It can be adjusted until the order is done.

Keep the work centres' *Cost per hour* at 0. Otherwise logged time is valued as well, and the
conversion cost is counted twice.
