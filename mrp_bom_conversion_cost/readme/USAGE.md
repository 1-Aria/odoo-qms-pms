1. An accounting administrator creates a rate under *Accounting → Configuration → Conversion Cost
   Rates* (also under *Manufacturing → Configuration*), with its start date and basis, and approves
   it. A rate cannot start before the day it is approved. A correction is a new rate with a later
   start date.
2. Enter *Conversion Minutes* on each normal bill of materials: the standard minutes per unit of the
   product. The bill's chatter tracks changes.
3. Before an order is done, Manufacturing administrators see its estimated extra unit cost. Once it
   is done, they see the figure, the rate and the minutes used.
4. A covered order cannot be marked done while the company has no approved rate in force.

Keep the work centres' *Cost per hour* at 0. Otherwise logged time is valued as well, and the
conversion cost is counted twice.
