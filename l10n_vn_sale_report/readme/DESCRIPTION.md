Prints sales orders in Vietnamese on the shared voucher layout of `l10n_vn_voucher`: both parties
(*Bên bán*, *Bên mua*), the delivery and payment terms, the lines, the totals with the amount in
words, our signers (*Người lập phiếu*, *Phụ trách kinh doanh*, *Giám đốc*) and the customer's
confirmation. The order is titled *Báo giá* before confirmation and *Xác nhận đơn hàng* after.

A compact version groups the variants of each style into one row (total quantity and amount),
with Odoo's size and colour grid beneath the lines.
