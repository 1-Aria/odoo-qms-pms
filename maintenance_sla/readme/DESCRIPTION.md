Gives maintenance requests configured response and restore commitments, measured on the stages
technicians already use, and records each commitment as its own evidence: what was promised, when
it was met, and whether it was on time.

A rule says which requests it applies to — by type, priority, team, equipment category, or an
extra filter — which stage meets it, which stages pause it, and how many hours are allowed. A
stage can be flagged to cancel open commitments, for outcomes such as scrapping.
