# odoo-qms-pms

Custom Odoo 18.0 CE modules for a unified Quality Management and Plant Maintenance pipeline, built on OCA modules.

See `docs/Odoo-QMS-PMS-Development-Plan.md` for the architecture.

## Requirements

- Odoo 18.0 Community Edition
- OCA repos (branch 18.0): management-system, maintenance, manufacture
- `mgmtsystem_nonconformity_quality_control_oca` is not merged in OCA yet. It comes from https://github.com/HeliconiaIO/management-system, branch `18.0-mig-mgmtsystem_nonconformity_quality_control_oca`.
