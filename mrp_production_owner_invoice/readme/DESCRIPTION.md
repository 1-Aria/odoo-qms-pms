Proposes the periodic invoice of processing done for an owner (contract processing, from
*MRP Production Partner Owner*). For one owner and one period, a wizard builds an ordinary draft
customer invoice: one processing-fee line per product style, with the quantity produced for the
owner and the fee from a pricelist, and one line for the company's material those orders consumed,
at cost. Journal items marked as late attributions are listed for the accountant to add. A second
invoice for the same period is warned about, never blocked.

Nothing is written but the draft invoice, so uninstalling the module leaves only ordinary records.
