1. Enable *Consignment* in *Inventory → Configuration → Settings*, so the *Owner* field shows on
   transfers.
2. On the operation type (*Inventory → Configuration → Operation Types*), tick *Partner Owns the
   Goods*. It is offered on receipt and internal types.
3. On a transfer of that type, choosing the partner sets the owner; validation sets it in any case
   when it is still empty.
