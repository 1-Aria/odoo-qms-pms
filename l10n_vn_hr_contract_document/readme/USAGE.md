1. On the company, set the legal representative and their title.
2. On each contract type, set *Contract Document*: labour, probation, training or none.
3. Under *Employees → Configuration → Contract Wording*, create the company's wording, or leave
   the generic texts.
4. On a contract, the warning at the top lists what the document still needs; *Print Draft*
   (payroll users) prints it, marked as a draft, with blanks where data is missing.
