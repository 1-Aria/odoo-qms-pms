1. Install OCA *Stock Owner Restriction*, which this module depends on. Leave *Owner restriction* on the
   manufacturing and *Pick Components* types on *Standard behavior*: the order decides.
2. On the manufacturing operation type used for processing (*Inventory → Configuration → Operation
   Types*), choose the partner in *Goods Owner*. Do the same on the subcontracting type if subcontracted
   orders are processing too.
3. Use a second manufacturing type without *Goods Owner* for the company's own production.
4. The order's *Goods Owner* shows in its *Miscellaneous* tab and can be changed while the order is draft
   or confirmed.
